# Assignment 7: Transfer Learning Comparison

## Aim
Use pretrained AlexNet, VGG-16, ResNet50 and EfficientNet-B0 for image classification and compare performance.

## Dataset
CIFAR-10 subset (5000 train / 1000 test) resized to 224x224, auto-downloaded.

## How to run
Open `Assignment_7.ipynb` in Colab with a GPU runtime and run all cells.

## What you get
Accuracy, macro-F1, parameter counts, training time table and charts for all four models.
