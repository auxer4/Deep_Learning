# Assignment 1: TensorFlow/Keras Setup and Data Preprocessing

## Aim
Install and configure TensorFlow/Keras in Google Colab; perform preprocessing, normalization, train-test split and visualization.

## Dataset
Wine dataset (`sklearn.datasets.load_wine`), loaded automatically.

## How to run
Open `Assignment_1.ipynb` in Google Colab (Runtime > Run all). No downloads needed.

## What you get
Environment check, missing-value handling, stratified split, StandardScaler/MinMaxScaler, histograms, boxplots, heatmap, pairplot, tf.data pipeline.
