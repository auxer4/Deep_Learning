# Assignment 6: CNN for Tomato Leaf Disease

## Aim
Design and implement a CNN for image classification using a tomato disease dataset.

## Dataset
PlantVillage (via `tensorflow_datasets`, `plant_village`), filtered to the 10 tomato classes. First run downloads ~0.8 GB.

## How to run
Open `Assignment_6.ipynb` in Colab with a GPU runtime and run all cells.

## What you get
Class preview, training curves, test accuracy, classification report, confusion matrix, saved model `tomato_cnn.keras`.
