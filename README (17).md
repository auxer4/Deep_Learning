# Assignment 8: BERT Sentiment Analysis

## Aim
Implement a pretrained BERT model for sentiment analysis / text classification.

## Dataset
IMDB reviews via Hugging Face `datasets` (4000 train / 1000 test subset).

## How to run
Open `Assignment_8.ipynb` in Colab with a GPU runtime and run all cells.

## What you get
Fine-tuned BERT, accuracy/precision/recall/F1, confusion matrix, live predictions.
