# Assignment 3: Forward/Backpropagation and Hyperparameter Analysis

## Aim
Implement forward propagation and backpropagation with TensorFlow/Keras; analyse learning rate and epochs.

## Dataset
Iris (`sklearn.datasets.load_iris`).

## How to run
Open `Assignment_3.ipynb` in Colab and run all cells (grid search takes a couple of minutes).

## What you get
Manual backprop verified against autodiff, loss curves per learning rate, lr x epochs accuracy heatmap, observations.
