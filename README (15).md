# Assignment 5: RNN vs LSTM vs GRU

## Aim
Implement and compare RNN, LSTM and GRU for sequence classification using appropriate evaluation metrics.

## Dataset
IMDB movie reviews (`keras.datasets.imdb`, 25k train / 25k test).

## How to run
Open `Assignment_5.ipynb` in Colab (GPU recommended) and run all cells.

## What you get
Comparison table (accuracy, precision, recall, F1, ROC-AUC, time, params), validation curves, confusion matrices.
