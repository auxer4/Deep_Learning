# Assignment 9: Vision Transformer vs CNN

## Aim
Perform image classification with a pretrained Vision Transformer and compare with a CNN.

## Dataset
CIFAR-10 subset (5000 train / 1000 test), 224x224, auto-downloaded.

## How to run
Open `Assignment_9.ipynb` in Colab with a GPU runtime and run all cells.

## What you get
Accuracy, macro-F1, parameters, train/inference time, loss curves and confusion matrices for ViT-B/16 vs ResNet50.
