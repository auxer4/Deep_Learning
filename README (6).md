# Assignment 10: Audio Classification with STT and TTS

## Aim
Design a deep learning application for audio classification that incorporates Speech-to-Text (STT) and Text-to-Speech (TTS), and evaluate with suitable metrics.

## Dataset
Google Speech Commands (10 keywords, ~2 GB download on first run). Whisper-tiny (STT) and gTTS (TTS) need internet.

## How to run
Open `Assignment_10.ipynb` in Colab with a GPU runtime and run all cells.

## What you get
Mel-spectrogram CNN (accuracy/F1/confusion matrix), Whisper STT with WER, gTTS TTS with round-trip WER, end-to-end voice assistant demo.
