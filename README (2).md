# Assignment 4: LSTM Time-Series Forecasting

## Aim
Develop an LSTM-based model for time-series forecasting (stock price).

## Dataset
AAPL daily close from Yahoo Finance via `yfinance` (synthetic fallback if offline).

## How to run
Open `Assignment_4.ipynb` in Colab and run all cells.

## What you get
Loss curves, RMSE/MAE/MAPE/R2, actual-vs-predicted plot, 30-day recursive forecast.
